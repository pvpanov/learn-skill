Regularisation is an important topic in machine learning, and it appears in many of the models that practitioners use every day.

For example, ridge regression uses an L2 penalty. Lasso uses an L1 penalty and can set coefficients to exactly zero. Elastic net combines both penalties. Dropout is used in neural networks. Early stopping is also a form of regularisation.

Regularisation reduces variance and increases bias. It helps with overfitting. The strength is controlled by a hyperparameter, usually chosen by cross-validation. Larger values mean more shrinkage. Standardisation matters for penalised models. Bayesian priors are related to penalties. Weight decay matches L2 in plain gradient descent but not in Adam.

In practice regularisation is almost always useful. Most libraries have sensible defaults. It is good to try several values. Results depend on the dataset. Regularisation is one of the key tools for building models that generalise well to new data.
